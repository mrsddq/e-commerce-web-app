# Frontend Quality Checklist

Use this when revisiting the e-commerce demo.

| Area | Check |
| --- | --- |
| Empty states | Empty cart, no search results, failed product load |
| Responsive states | Product grid, cart, checkout summary on mobile |
| Data handling | Price formatting, quantity bounds, missing images |
| Accessibility | Button labels, focus order, color contrast |
| Verification | Add React build/test command and one screenshot per core flow |

Best next technical step: add a small component test suite for cart totals and quantity changes.
