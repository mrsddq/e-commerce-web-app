# Demo Checklist

Use this before presenting the storefront as more than a learning app.

## Local Demo

```bash
cd amazon
npm install
npm start
```

## Screenshots To Capture

- Product grid at desktop width.
- Product grid at mobile width.
- Search results.
- Cart count and total after adding items.

## Upgrade Path

- [ ] Add persisted cart state.
- [ ] Add product detail route.
- [ ] Add checkout placeholder page with clear non-payment wording.
- [ ] Deploy to GitHub Pages, Netlify, or Vercel.
- [ ] Add UI smoke tests.
